# AstrBot 跑团角色卡插件 (TRPG Player)

为 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 提供的一个基础 TRPG（跑团）角色卡记录插件。支持全局唯一角色卡、六围数值动态购买、积分管理以及内置的积分商店功能。

## ✨ 核心特性

- **全局角色卡**：每个 QQ 用户绑定一张全局唯一的角色卡，多群互通。
- **积分经济系统**：初始提供 1000 积分。玩家可消耗积分提升自身六围属性（100积分 = 1点属性），或者在商店购买物品与技能。
- **内置交易商店**：超管可上架物品与技能，玩家消耗积分购买，不支持重复购买同名物品。
- **超管特权**：支持直接 `@用户` 或输入 `QQ号` 对玩家数据（角色删除、属性强改、积分修改、物品技能修改）进行干预。

## 🛠️ 安装说明

1. 确保你的 AstrBot 版本 >= `4.9.2`。
2. 将此仓库克隆至 `AstrBot/data/plugins/` 目录下，并确保文件夹名称为 `astrbot_plugin_trpg_player`。
3. 重启 AstrBot 或在 WebUI 管理面板中点击重载插件。

## ⚙️ 插件配置

在 AstrBot WebUI 面板 -> 插件配置中，找到本插件：

- **super_admins (超级管理员列表)**：填写超级管理员的 QQ 号（列表形式）。超管可以执行所有后台管理、强制修改以及商城上架操作。

## 📖 指令列表

### 玩家基础指令

*普通玩家即可使用的指令：*

- `/登记 [角色名]`：创建你的角色卡。初始六围全为 10，积分 1000。
- `/面板`：查看你的个人面板（含姓名、性别、属性、积分、物品、技能与血统）。
- `/修改姓名 [新姓名]`：修改你当前的角色名。
- `/修改性别 [新性别]`：修改你当前的角色性别。
- `[属性名] [+/-数值]`（或 `/属性名 [+/-数值]`）：使用积分买卖基础属性。支持的属性：`力量`、`速度`、`智力`、`体力`、`精神力`、`免疫力`。
  - 例如：`力量 +1`（扣除 100 积分），`力量 -1`（返还 100 积分）。
  - *注意：积分不能被直接当作属性买卖。*

### 🛍️ 商店指令

*交易商城相关指令集：*

- `/商店 列表`：查看当前商店在售的所有物品、技能和血统及其价格。
- `/商店 购买 [名称]`：花费积分购买物品/技能/血统。如果已有该物品将提示无法重复购买。
- `/商店 上架 [名称] [价格] [可选:物品/技能/血统]` **[超管]**：上架商品，不填类型默认当做“物品”处理。例如 `/商店 上架 屠龙宝刀 500` 或 `/商店 上架 吸血鬼 2000 血统`。
- `/商店 下架 [名称]` **[超管]**：从商店中删除指定商品。

### 👑 超级管理员特权指令

*需在 WebUI 配置中填入超管 QQ 才能使用。支持 `@某人` 或者 `[QQ号]`。*

- `/登记 @某人 [角色名]`：直接为某人创建一张角色卡。
- `/查看面板 @某人`：查看其他用户的面板。
- `/删除角色 @某人`：删除某人的角色卡。
- `/强制修改 @某人 [属性] [+/-数值]`：直接修改某人的属性或积分（强制修改不触发积分扣除逻辑）。例如 `/强制修改 @某人 积分 +1000`。
- `/增加物品 @某人 [物品名]`：凭空给某人发放指定物品。
- `/删除物品 @某人 [物品名]`：从某人身上收回指定物品。
- `/增加技能 @某人 [技能名]`：凭空给某人发放指定技能。
- `/删除技能 @某人 [技能名]`：从某人身上收回指定技能。
- `/增加血统 @某人 [血统名]`：直接给某人设置血统。
- `/删除血统 @某人`：将某人的血统重置为“无”。
